# ALASEEL TECH — موقع ثلاثي الأبعاد

موقع أعمال عربي (RTL) مبني كفضاء رقمي واحد متصل بدل صفحات منفصلة.
يبدأ باسم الاستوديو في المركز، ثم تنمو حوله شبكة من الأقسام، وتتحرك
الكاميرا داخلها بدل أن تُستبدل الصفحات.

**التقنيات:** [Vite](https://vite.dev) · [Three.js](https://threejs.org) · [GSAP](https://gsap.com)
بلا إطار عمل واجهة، وبلا خادم — ملفات ثابتة فقط.

---

## التشغيل

```bash
npm install
npm run dev          # على هذا الجهاز:  http://localhost:5173/alaseel-tech-3d/
npm run dev:mobile   # يتيحه لأجهزة الشبكة نفسها (هاتف/تابلت)
npm run build        # نسخة الإنتاج في مجلد dist/
npm run preview      # معاينة نسخة الإنتاج
```

للإيقاف: `Ctrl + C`

## كيف يعمل

| الحالة | ما يحدث |
|---|---|
| **البداية** | اسم الاستوديو في المركز، ينبض بهدوء |
| **الفضاء** | شبكة عقد وخطوط تنمو من المركز، والأقسام موزّعة فيها |
| **قسم** | الكاميرا تنتقل مكانيًا إليه، وتتشكّل كوكبة عناصره، وتتلاشى بقية الأسماء |
| **فرع** | لوحة زجاجية بعمودين: رزنامة صور تنقلب + وصف وزر طلب |

**لا انتقالات صفحات إطلاقًا** — كل شيء تحوّل مكاني داخل مشهد واحد.

## قرارات تقنية تستحق الذكر

**النص العربي داخل WebGL.** Three.js لا يعرف كيف يصل الحروف العربية. لذلك
يُرسم كل نص على `canvas` أولًا (المتصفح يصله بشكل صحيح) ثم يُستخدم كصورة.
انظر [`src/core/textTexture.js`](src/core/textTexture.js).

**الحركة على كرت الشاشة لا المعالج.** نمو الشبكة، رسم الخطوط، وتفكك
الجزيئات كلها تُدار بمتغيّر واحد داخل shader. آلاف الجزيئات بتكلفة رقم واحد.
انظر [`src/scenes/particles.js`](src/scenes/particles.js).

**التأطير محسوب لا ثابت.** مسافة الكاميرا تُشتق من نسبة أبعاد الشاشة، فتدخل
كل الأقسام داخل الإطار على شاشة الهاتف الطويلة كما على الشاشة العريضة.

**اللمس ليس فيه تمرير.** الاختيار يُحسب لحظة رفع الإصبع مباشرة، لا من حالة
تمرير محسوبة في إطار سابق.

**الجودة تتكيّف.** يُقاس معدل الإطارات باستمرار، وتنخفض كثافة الجزيئات
ودقة الرسم تلقائيًا على الأجهزة الضعيفة.

**ينهض من الأعطال.** فقدان سياق WebGL (شائع على الهاتف عند تبديل التطبيقات)
يُلتقط ويُستأنف. جهاز بلا WebGL يحصل على النسخة النصية الكاملة.

## إمكانية الوصول

- نسخة نصية دلالية كاملة تقرأها محركات البحث وقارئات الشاشة، مولّدة من
  نفس ملف المحتوى فلا تتعارض مع المشهد.
- تنقّل كامل بلوحة المفاتيح: أسهم · `Enter` · `Escape`.
- زر عودة دائم، ودعم زر الرجوع في المتصفح وروابط `#/`.
- وضع بديل يحترم `prefers-reduced-motion`.
- الأرقام معزولة بـ`<bdi>` فلا تنقلب في النص العربي.

## الأمان

- سياسة أمان محتوى (CSP) تمنع أي سكربت من خارج الموقع.
- قائمة بروتوكولات مسموحة للروابط، وتحقق من صيغة الألوان قبل حقنها في CSS.
- `rel="noopener"` على كل رابط خارجي.
- ترويسات أمان للنشر في [`public/_headers`](public/_headers).
- لا يوجد خادم ولا قاعدة بيانات — لا سطح هجوم من جهة الخادم.

## تعديل المحتوى

كل النصوص وبيانات التواصل في ملف واحد: [`src/data/content.js`](src/data/content.js)
— الأقسام، الفروع، آراء العملاء، والرقم والبريد.

> ⚠️ **آراء العملاء الحالية نماذج للعرض.** استبدلها بشهادات حقيقية
> بإذن أصحابها قبل النشر.

الصور في [`public/images/services/`](public/images/services) — خمس صور لكل قسم.
أي قسم بلا صور يستخدم رسمًا يولّده المتصفح بلون القسم، فلا تظهر صورة مكسورة أبدًا.
